# Monkey D — Flutter UI Starter

This is an initial UI prototype for the Monkey D international messaging app.

## Included
- Arabic-first glassmorphism home screen
- Mock chat list
- Bottom navigation for chats, calls, contacts, and settings
- Glass panels and soft gradient background

## Run
1. Install Flutter SDK and Android Studio or Xcode.
2. In this directory run: `flutter pub get`
3. Run on a device or emulator: `flutter run`

## Important
This is a UI starter only. No real accounts, messaging backend, calls, push notifications, telephone carrier integration, or end-to-end encryption are connected yet. Do not describe the app as secure or production-ready until those systems are implemented and tested.

## Planned implementation
1. Authentication and user profiles
2. Backend and real-time messaging
3. WebRTC voice/video calling and call signaling
4. Push notifications and native incoming-call handling
5. End-to-end encryption using a reviewed protocol/library
6. Optional PSTN calling via a licensed voice provider
7. Privacy, abuse prevention, testing, and store deployment
